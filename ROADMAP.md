# Shiplogue roadmap notes

## Version ladder

- `0.1.x` continues through **0.1.20**.
- The next minor after `0.1.20` is **`0.2.1`**, not `0.2.0`.
- The agent/plugin track is versioned independently (`0.3.x` for the public
  Shiplogue Agent package), but the rule above applies to the extension release
  ladder.

## Current release

- Extension: **0.1.15** prepared (version, changelog, release notes, VSIX).
- Agent: **0.3.0-dev.1**, private/unpublished.
- Claude plugin: validated, not publicly published; see `PUBLISHING.md`.
- Cloud agent contract: `AGENT_CLOUD_CONTRACT.md`.

## Reminder

When the extension reaches **0.1.20**, cut the next release as **0.2.1**.
Do not call it 0.2.0.
